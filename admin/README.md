# EverKB 管理后台（admin）

Vue 3 + Vite 单页应用，面向平台管理员/运营者。页面清单见 [`../docs/2026-11-14-rag知识库管理平台-设计文档.md`](../docs/2026-11-14-rag知识库管理平台-设计文档.md) §7：登录（JWT）、知识库管理、文档管理、md 编辑器、chunk 查看、应用管理、问答记录、**Trace 查看器**、对账工具。

- 仅消费后端 REST/SSE API，不直连 MySQL / Milvus
- 工程尚未初始化；按排期在「计划 3（前端最小演示页）」启动时执行 `npm create vite`
- 演示优先级排序见 [`../docs/2026-11-15-开发执行排期.md`](../docs/2026-11-15-开发执行排期.md) §6
